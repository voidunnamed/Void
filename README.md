## `> whoami`

I'm **Void**, a development student specialized in the **JVM ecosystem**, with **Java** as my main language.

I like building systems that are modular, extensible and just complex enough to make me regret saying *"it should be easy."*

- ☕ Mainly working with **Java 21**
- 🧩 Building **plugins, RPG systems and developer tooling**
- 🏗️ Interested in **clean architecture, modularity and maintainable code**
- 🧠 Learning through projects: build → break → understand → refactor
- 🎮 Often turning game ideas into technical problems on purpose
